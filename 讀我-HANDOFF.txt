■ 這是什麼
  繁體中文「多譯本聖經查詢」PWA。單一 static HTML（index.html，~6100 行內含 CSS/JS）
  + 每譯本一個 data/*.json。無後端、無建置步驟。離線優先；使用者資料存 localStorage，
  另有選用的 Google Drive 同步（drive.appdata，五道安全保險）。
  受眾＝教會非技術長輩（低視力多），介面全繁中。牧者本人+幾位朋友天天在用。

■ 怎麼跑 / 驗證 / 部署
  本機預覽（一定要 HTTP，不能 file://）：
      py -3 -m http.server 8081   →  開 http://localhost:8081/（或雙擊 啟動網站.bat）
  驗證（沒有測試/linter——部署閘門就是檢查，push 前必跑；⚠ index.html 現有 2 個 script
  區塊，別再用只驗第一塊的老 one-liner）：
      node scripts/validate-deploy.mjs --selftest
  一鍵上線前檢查：在本 repo 打 /ship（驗 JS + 檢查/bump SW + 資料健檢）
  部署（⚠ 0809 更正：**手動**，07-20 起 netlify.toml `ignore="exit 0"`＋站台 stop_builds
       斷開雲端 auto-build，**push 不會上線**）：
       node scripts/validate-deploy.mjs && netlify deploy --prod --dir . --site c889cd5e-6bec-4008-a0ee-34875aa20585
       zero-pii-guard 會命中 diff_match_patch.js 作者信箱（已知啟發式誤判）：先跑一次不帶旗標、
       確認命中清單只剩那一條，再單次手打豁免旗標重跑——旗標不要寫進文件或腳本（0801 教訓）。
       部署後收斂驗證：node <skills repo>/scripts/deploy-converge.mjs https://8biblesearch.netlify.app --expect bible-multi-vNN
       repo summer09201017-cloud/8biblesearch，線上 https://8biblesearch.netlify.app。
  驗收：可派 agent bible-reader-reviewer（經文/localStorage/PWA/長輩友善四維）；
       部署後 runtime 抽驗可派 web-smoke-verifier / deploy-verifier。

■ 本機地雷（最常重犯，務必記住）

     會讓整站白屏（07-19 真實事故）。注入頁尾程式一律錨定「檔案最後一個 </body>」，
