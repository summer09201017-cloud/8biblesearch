■ 本機地雷（最常重犯，務必記住）
  0) 🚨 buildNotesPrintHtml() 的模板字串裡有一份完整 </body></html> 假文件——任何
     「注入 snippet 到 </body> 前」的批次腳本都會插錯進字串裡，字串內未跳脫的 </script>
     會讓整站白屏（07-19 真實事故）。注入頁尾程式一律錨定「檔案最後一個 </body>」，
     改完跑 node scripts/validate-deploy.mjs --selftest。
  0b) VERSE_COUNTS 常數別手改——由 data/*.json 程式化重生成（9 版最大值），閘門會逐格對賬。
  1) 改 index.html / manifest / icons 後，一定要 bump sw.js 的 CACHE_NAME=bible-multi-vN，
     否則已安裝 PWA 的使用者卡在舊殼層。**目前 v93**。（repo 有 hook 提醒；/ship 會自動 bump。）
  1b) ⚠ **這台機 core.autocrlf=true**：用編輯工具改 index.html 會把**整檔翻成 CRLF**，
     實測 git 沒有在 commit 時正規化回來 → diff 變成「8234 增 / 7936 減」把真實的 3 行改動埋掉。
     commit 前先把行尾轉回 LF（本輪 v92 第一次 commit 就是這樣，amend 修掉後才是 317/19）。
  1c) ⚠ **別在原始碼裡寫字面控制字元**（NUL 之類）。v92 把 2 個 U+0000 當佔位符烤進 index.html
     並上線；功能正常但看不見。要用就寫 '\0' 轉義。git 的 binary 判定只掃前 8000 位元組，
     所以大檔反而藏得住——**體積本身就是偽裝**。
  1d) ⚠ **驗收要量「看得見」,不要只讀 innerText**：`innerText` 對 `display:none` 的元素會
     **退回 textContent** ⇒ 面板隱藏著也讀得到字，「驗過了」其實沒上螢幕（本輪踩過）。
     用 `getBoundingClientRect()` 寬高 > 0 才算可見。同理 Playwright 要用真 click 不要 evaluate。
  2) HFP 那台的正本 clone 在 C:\Users\HFP\Downloads\hfpc\8biblesearch。
     它 Downloads 下的「聖經查詢CUR-交接-2026-06-29」資料夾是舊快照（比遠端舊），別用；
     裡面還有 2 層同名巢狀舊副本各帶 .git（roadmap 待做 #4 是清掉它們，需牧者點頭）。
     agape250 這台：直接 git clone / git pull 遠端即可，別解壓舊 zip 蓋新版。
  3) localStorage 的 try/catch 不要拆（Safari 私密模式會丟例外）。
  4) 桌機與手機共用同一段 DOM；版面差異一律用 @media (max-width:600px)，別動桌機。
  5) 新增 localStorage 鍵時，記得接進備份鏈四站（匯出/匯入/快照/雲端 payload），
     不然換手機該鍵資料就丟了（讀經足跡 readingLog 是照做的範例）。
