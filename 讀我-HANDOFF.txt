■ 怎麼跑 / 驗證 / 部署
  本機預覽（一定要 HTTP，不能 file://）：
      py -3 -m http.server 8081   →  開 http://localhost:8081/（或雙擊 啟動網站.bat）
  驗證內嵌 JS 能 parse（沒有測試/linter，這是唯一檢查）：
      node -e "const fs=require('fs'),m=fs.readFileSync('index.html','utf8').match(/<script>([\s\S]*?)<\/script>/);new Function(m[1]);console.log('JS OK')"
  一鍵上線前檢查：在本 repo 打 /ship（驗 JS + 檢查/bump SW + 資料健檢）
  部署：push main → Netlify 自動部署（repo summer09201017-cloud/8biblesearch，
       線上 https://8biblesearch.netlify.app）。
  驗收：可派 agent bible-reader-reviewer（2026-07-03 新建，經文/localStorage/PWA/長輩友善四維）。

  2) HFP 那台的正本 clone 在 C:\Users\HFP\Downloads\hfpc\8biblesearch。
     它 Downloads 下的「聖經查詢CUR-交接-2026-06-29」資料夾是舊快照（比遠端舊），別用；
     裡面還有 2 層同名巢狀舊副本各帶 .git（roadmap 待做 #4 是清掉它們，需牧者點頭）。
