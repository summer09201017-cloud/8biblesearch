■ 怎麼跑 / 驗證 / 部署
  本機預覽（一定要 HTTP，不能 file://，因為要 fetch data/*.json）：
      py -3 -m http.server 8081   →  開 http://localhost:8081/
      （或雙擊 啟動網站.bat）
  驗證內嵌 JS 能 parse（這專案沒有測試/linter，這是唯一檢查）：
      node -e "const fs=require('fs'),m=fs.readFileSync('index.html','utf8').match(/<script>([\s\S]*?)<\/script>/);new Function(m[1]);console.log('JS OK')"
  一鍵上線前檢查：在本 repo 打  /ship  （驗證 JS + 檢查/bump SW + 資料健檢 + 部署提醒）
  部署：push main → Netlify 自動部署（repo summer09201017-cloud/8biblesearch）。

■ 本機地雷（最常重犯，務必記住）
  1) 改 index.html / manifest / icons / vendor 後，**一定要 bump sw.js 的 CACHE_NAME=bible-multi-vN**，
     否則已安裝 PWA 的使用者卡在舊殼層。目前 v53。（本 repo 有 hook 會自動提醒；用 /ship 會自動 bump。）
  2) 這個資料夾底下還有 **2 層同名巢狀舊副本**（聖經查詢CUR/聖經查詢CUR/...），各自一個 .git，是舊備份。
     **別改錯層、別 commit 錯 repo**。正本＝最外層（index.html 約 277KB 的這個）。roadmap 待做 #2 是清掉它們（需點頭）。
  3) localStorage 的 try/catch 不要拆（Safari 私密模式會丟例外）。
  4) 桌機與手機共用同一段 DOM；版面差異一律用 @media (max-width:600px) 處理，別動桌機。
