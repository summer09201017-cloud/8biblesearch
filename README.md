# 多譯本聖經查詢（PWA）

離線可用的多譯本聖經查詢網頁。單一 static HTML + 各譯本 JSON，無後端、無建置步驟，部署到 Netlify 即可。

**譯本（10 種）**
- **離線 9 種**（打包在 `data/`，完全離線可用）：和合本 (unv)、新譯本 (ncv)、呂振中 (lcc)、ESV、NIV、KJV、ASV、WEB、BBE。
- **線上 1 種**：**和修本／和合本2010 (rcuv)** — 勾選時才逐章向信望愛查詢，需連線，不打包。
  選單上該項旁邊有小字「線上」提醒。

## 功能

- **經文閱讀**：多譯本並排／堆疊、連讀模式（章末自動接下一章）、字體大小調整、記住上次位置。
- **🔊 朗讀經文**：用瀏覽器內建語音朗讀目前畫面的經文（零音檔、可離線、免費）；可用「版本選擇器」挑要朗讀的中文或英文譯本；裝置沒對應語音時安靜略過。
- **📖 和修本（和合本2010）**：在「顯示譯本」勾選即可與和合本並排對照（一邊「神」、一邊「上帝」，用字差異一眼看得出來）。和修本的**段落小標**會顯示在該節上方；譯者的**譯註**（「或譯…」）收成經文中的小標記 `[1]`，**點一下才展開**，所以經文本身讀起來乾淨、複製與朗讀也不會帶到註腳。
  ⚠ 和修本是**線上譯本**，需連線；沒連線時只有它讀不到（畫面會明說，其餘 9 本不受影響）。
  ⚠ **關鍵字搜尋不包含和修本**（線上譯本只取讀過的章，無法全文搜尋）——想看某節的和修本，用「經文閱讀」或「快速查詢」翻到那一章。
- **關鍵字搜尋**：支援多關鍵字 AND（空白／逗號分隔）；可勾選經節，複製／LINE／Email 分享。
- **快速查詢**：一次輸入多段經文出處（逗號或換行分隔）。
- **對讀比較**：任選基準與對比譯本做差異比對（中文逐字、英文逐詞），支援單節／範圍／三版本同時比較，附相似度。
- **我的筆記**：分類、標籤、釘選、書籤、禱告／問題狀態、時間軸；可匯出 Markdown 或列印 PDF。
- **📖 讀經足跡**：查了就自動打卡——閱讀一章停留 15 秒（或快速查詢整章）自動記錄；今日／連續天數／全卷 % 統計、本月～歷年任意範圍的「這章被讀幾次」排行、全卷 1189 章足跡地圖（點格子直接翻開那章）。記錄只存自己裝置、每人進度獨立；可在設定停用或清除。
- **🏆 讀完一卷書里程碑**：某卷書的每一章都讀過，讀完當下放彩帶慶祝；足跡頁掛上金色 🏆 徽章，並顯示「還差幾章就讀完」的下一個目標。
- **📤 本月讀經卡**：足跡頁一鍵把本月讀經足跡（日曆熱圖＋統計＋金句）做成一張圖，直接分享到 LINE 小組互相激勵（不支援分享的裝置自動改為下載）。
- **四種主題（護眼）**：米紙／印刷棕／深色／純黑。
- **資料備份**：JSON 匯入匯出；選用 Google Drive 同步（只存到使用者自己的 App 專屬資料夾，五道安全保險）。「啟動時自動連結 Google」可在設定關掉——關掉後開 App 完全不碰 Google，要備份時再手動連結。
- **可安裝**：加入手機主畫面，離線使用（PWA）。

> 手機版頂部已精簡（隱藏大標題、控制列移到底部）、經文卡片加寬貼近邊界，方便長輩閱讀。

## 本機預覽

需用靜態伺服器（要能 fetch `data/`，不能直接 file:// 開）：

```powershell
py -3 -m http.server 8081      # 然後開 http://localhost:8081/
```

或雙擊根目錄的 `啟動網站.bat`。

## 資料檔

執行 `node download_bible.js` 自 [信望愛 qb.php](https://bible.fhl.net/json/qb.php) 下載譯本到 `data/`。NIV 等流程見 **`DEPLOY.md`**。

## 部署與更新

⚠ **部署是手動的（2026-07-20 起）**：`netlify.toml` 的 `ignore = "exit 0"` ＋站台 `stop_builds` 已斷開雲端 auto-build（每次 push 都 build 會燒點數）——**push 不會上線**。發佈指令：

```powershell
node scripts/validate-deploy.mjs && netlify deploy --prod --dir . --site c889cd5e-6bec-4008-a0ee-34875aa20585
```

**改動 `index.html`／manifest／icons 後，務必把 `sw.js` 的 `CACHE_NAME` 版本號 +1**，否則已安裝的使用者會看到舊版。可在本 repo 用 `/ship` 指令一鍵檢查。完整步驟見 **`DEPLOY.md`**。

**部署閘門（2026-07-19 起）**：每次部署 Netlify 會先跑 `node scripts/validate-deploy.mjs --selftest`——任何檢查失敗（內嵌 JS 壞掉、資料檔損毀、章節數常數與資料不符…）部署直接失敗、**線上維持前一版**，並寄失敗通知信。本機 push 前全域 hook 也會跑同一支腳本。手動驗證：

```powershell
node scripts/validate-deploy.mjs --selftest
```

## 授權與聲明

經文版權各歸原譯本／來源所有；使用請遵守相關條款。NIV 等需 API 金鑰之流程見 `DEPLOY.md`。

**和修本（和合本2010）**版權屬香港聖經公會，本站經 [信望愛 JSON API](https://bible.fhl.net/json/) **即時查詢**呈現，不下載、不打包、不重新散布——信望愛在該 API 的譯本清單（`abv.php`）對此譯本標示 `candownload=0`（不可下載離線資料庫），文件並註明部分譯本僅授權該站使用。
